# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это за проект
Персональная About-страница («визитка») Андрея — раскрывает его подход к делу как учредителя компании по поставке климатического оборудования (вентиляция и кондиционирование, aeroheat.by) для потенциальных клиентов и партнёров.

## Как просмотреть
Сайт опубликован через GitHub Pages: https://memento-mori-1.github.io/persona2/
Локально — открыть `docs/index.html` в браузере (двойной клик, или в PowerShell: `Start-Process docs/index.html`).

## Архитектура
- `docs/index.html` — единственный рендерящийся файл, экспортированный бандл дизайн-канвы (Claude Design). Это не обычный HTML: разметка, стили и картинки упакованы внутрь и распаковываются в браузере скриптом при загрузке. Файл **не редактируется вручную** — правки вносятся через исходный дизайн-канвас, откуда файл был экспортирован повторно.
- `docs/images/` — фотографии, используемые в бандле (football.jpg, portrait.png, bubble-web.jpg, expo-fan.jpg, expo-bvn.jpg).
- `про-меня.md`, `проекты.md`, `факты.md` — исходные тексты о содержимом страницы (кто Андрей, чем занимается, интересные факты). Если реальная информация меняется, обновлять сначала здесь, потом переносить в дизайн-канвас при следующем экспорте.
- `profile.md` — сводная версия тех же материалов в другой структуре (Кто я / Чем занимаюсь / Сильные стороны / Интересы / Что хочу построить). На странице не отображается — служит контекстом для дальнейших этапов курса.
- `Дизайн сайта-визитки.zip` — архив с оригинальным дизайном (в .gitignore, не попадает в репозиторий).
- Папка `docs/` (а не `dist/`) выбрана специально — GitHub Pages умеет отдавать сайт из `docs/` в ветке `main` без дополнительной настройки.

## Цель проекта
Сайт раскрывает подход Андрея к делу как учредителя компании-поставщика климатического оборудования и рассказывает о нём потенциальным клиентам — цифровая визитка/About-страница.

## Тон и стиль
Прямой, без воды, по делу — соответствует девизу «Что обещал — то и приедет». Не сухой корпоративный тон, но и не панибратский: деловая прямота.

## Ограничения
- `docs/index.html` — сгенерированный файл, руками не трогаем; изменения контента вносим через markdown-файлы и пересборку/переэкспорт дизайна.
- Автор не программист: любое изменение должно оставаться простым и проверяемым — если что-то не показывается прямо в браузере, объяснять понятно, без жаргона.
- Реальные данные компании (email, сайт, объекты, цифры) — конфиденциальные детали бизнеса, менять только по прямому указанию Андрея.
